# DAA — Design & Analysis of Algorithms

Course repository for **Design & Analysis of Algorithms (DAA)** at **Ala-Too International University (AIU)**.

## Course focus

The goal of the course is to develop the ability to **analyze, design, justify, and implement algorithms** rather than only memorize them.

By the end of the course, the expected workflow is:

**Problem → Algorithm → Correctness / Reasoning → Complexity → Implementation → Testing**
