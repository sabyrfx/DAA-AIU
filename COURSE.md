# Course Overview — Design & Analysis of Algorithms

## Core objective

By the end of the course, you should be able to do four things:

### 1. Analyze
Determine **time complexity** and **space complexity** using:
- asymptotic notation
- recurrences

### 2. Design
Select an appropriate algorithmic paradigm and construct an efficient algorithm.

### 3. Justify
Explain:
- correctness
- assumptions
- trade-offs
- limitations

### 4. Implement
Translate an algorithm into clear code and test it against edge cases.

A useful way to think about the course is:

**Problem → Algorithm → Correctness / Reasoning → Complexity → Implementation → Testing**

---

## Key concepts to become familiar with

The course builds around concepts such as:
- algorithms
- data structures
- time complexity
- space complexity
- asymptotic analysis
- Big O notation
- binary search
- recursion
- recurrence relations
- divide and conquer
- brute force
- greedy algorithms
- dynamic programming
- backtracking
- branch and bound
- reduction / transform-and-conquer

For every important algorithm, aim to answer:
1. How does it work?
2. Why does it work?
3. What is its time complexity?
4. What is its space complexity?
5. What assumptions does it rely on?
6. What are its trade-offs or limitations?
7. When should it be used?

## Expected learning mindset

When solving a task, do not stop at writing code. Work through the full reasoning process:

1. What is the input?
2. What output is required?
3. What properties does the data have?
4. Which data structure is suitable?
5. Which algorithmic approach fits the problem?
6. Why is the algorithm correct?
7. What is its time complexity?
8. What is its space complexity?
9. Can it be improved?
10. Which edge cases should be tested?

The main goal is to become able to **analyze algorithms, solve problems using them, and explain why the chosen solution works and how efficient it is**.
