# Week 02

## Focus

Teacher-assigned LeetCode problems.

## Objective

The goal of this assignment is not only to solve the problems, but to **understand and analyze your own solution**.

For each problem:

1. Write your own solution.
2. Explain how your algorithm works.
3. Define the **time complexity**.
4. Define the **space complexity**.
5. Explain **why** your solution has these complexities.
6. If you find a more efficient solution, briefly explain what can be improved.

### Important

**Rule of thumb: Better your own brute-force solution than a borrowed optimal solution. Analysis is key.**

Do not worry if your first solution is not optimal.

For this assignment, optimization requirements in the original problem descriptions may be ignored for now, such as:

- “Write an algorithm with O(log n) runtime complexity.”
- “Minimize the number of calls to the API.”

These requirements describe the intended optimized solution, but they are **not required yet**.

Start with:

**Solve → Understand → Analyze → Explain → Improve**

For example, an **O(n)** solution is acceptable if you can correctly explain **why it is O(n)**.

If you later find an **O(log n)** solution, explain what changed and why the new solution is more efficient.

## Structure

All task work for this week is stored in `Tasks/`.

Each task should document:
- Task description
- Goal
- Your own solution
- How the algorithm works
- Time complexity
- Space complexity
- Why those complexities apply
- Possible improvements / more efficient approaches
